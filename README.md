# Flutter KT5. Приложение с пользователем

Flutter-приложение с простой авторизацией и сохранением данных пользователя в локальном хранилище.

## Функциональность

* Ввод данных пользователя (имя и email)
* Сохранение данных локально
* Автоматическая авторизация при повторном запуске
* Отображение данных пользователя на главном экране
* Выход из аккаунта (logout)

## Запуск проекта

```bash
flutter pub get
flutter run
```

## Логика работы

Если пользователь уже авторизован, сразу открывается главный экран. Иначе отображается экран входа.
